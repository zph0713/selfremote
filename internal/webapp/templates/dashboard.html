下载与部署

客户端（Mac / Windows / Linux）：GitHub Releases —— 配合本页「客户端密钥」中生成的 .srkey 文件使用。

站点 Agent：在「站点 Agent」里创建站点后，把页面给出的安装命令粘到目标机器上执行即可 （一行搞定；不联网的机器可用「离线部署包」）。

服务端（中转 + 控制面，推荐 compose 全家桶）：ghcr.io/zph0713/selfremote:latest（离线镜像包、部署文档同在 Releases 页）。

单机最小部署（中转服务端，无需 TUN / 特权）：

docker run -d --name selfremote-server --restart unless-stopped \
  -p 28333:28333/udp -p 127.0.0.1:8770:8770 \
  -v /etc/selfremote:/etc/selfremote \
  ghcr.io/zph0713/selfremote:latest server -c /etc/selfremote/server.json
{{end}}
